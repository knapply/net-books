# Cyber networks (outline only)

Planned second book. No chapters yet: the first book fixes the shared tooling
and style, then this book gets its own `outline.toml` and the same
`tools/new_chapters.py` stamps its chapters.

Working scope, to settle before writing:

- Network data from systems: flows, logs, topology, dependency and attack graphs.
- Graph measures applied to those data: reachability, choke points, resilience,
  community structure, temporal paths.
- Method over operations: public datasets and published methods only.

Shared with the first book: `shared/` (formats, print settings, bibliography),
the three-language example block, and the build tools.
