# Figures

Generated by `python3 tools/make_figures.py` (standard library only) into `books/<book>/figures/`.
Add `--snippets` to print the markdown to paste into a chapter.

House style:
- Okabe-Ito colours; shape and line style repeat what colour says, so figures survive greyscale printing.
- Text is real text. Every figure has a `<title>`, a `<desc>`, a caption and `fig-alt` text.
- One idea per figure, and not only network pictures: flows, tables and comparisons count.
- `tools/check_books.py` fails on a missing file or empty `fig-alt`.
